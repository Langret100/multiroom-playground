# 블룸샷 — 플레이그라운드용 최종 통합본

## 적용

이 패치는 플레이그라운드 원본의 루트에 그대로 덮어쓰는 방식입니다. Worker/서버 교체는 필요하지 않습니다. 적용 후 캐시가 남으면 `Ctrl+F5`로 새로고침하세요.

## 게임 구조

- 1인 CPU 연습 또는 2~8인 온라인 포격 대전
- 정령 8종, 각기 다른 체력/이동력/발사각/일반탄/특수탄
- 각도, 파워, 바람, 파괴되는 지형을 이용하는 턴제 포격
- 시작 아이템: 2연발, 파워 ×2, 회복 50%
- 추가 보급: 이동 충전, 보호막, 독안개, 서리 탄, 바람 반전
- 25초마다 낙하산 보급. 낙하산을 포탄으로 맞히면 급강하

## 캐릭터 에셋

전투 캐릭터는 8종 모두 픽셀아트 스프라이트 시트를 사용합니다. 각 시트는 4×4 정수 셀로 구성되며 실제 게임에서는 다음 상태를 사용합니다.

- 대기 4프레임
- 이동 2프레임
- 이동 중 걸림
- 발사
- 점프/낙하
- 착지
- 체력 50% 이하
- 체력 10% 이하

캐릭터는 발밑 충돌 지형의 기울기를 계산해 경사면에 맞춰 기울어집니다. 선택창/프로필/HUD 초상도 같은 새 픽셀 캐릭터를 사용합니다.

## 맵

맵은 5종입니다.

- 거목의 다리
- 안개 공중정원
- 서리 균열
- 황혼 철골
- 별빛 유적

각 맵은 파괴되지 않는 전용 배경 이미지와 파괴되는 전경 지형 이미지로 나뉩니다. `map-solids.js`의 충돌 데이터는 전경 지형 이미지의 알파 형태를 기준으로 미리 생성되어 있어 **보이는 전경 지형과 실제 이동/충돌 지형이 같은 기준**을 사용합니다.

폭발 시 엔진의 `destroy()`가 현재 `solids`에서 해당 영역을 제거하고, 렌더러 역시 같은 `solids`를 클리핑 마스크로 사용합니다. 따라서 지형을 쏘면 보이는 땅과 실제 충돌 판정이 함께 사라집니다. 구멍 아래에 다른 발판이 있으면 낙하해 착지하며, 맵 아래로 떨어지면 낙사합니다.

맵 전체 이미지는 WEBP lossless이며, 선택창에서는 작은 preview만 먼저 로드하고 실제 고해상도 배경/전경은 현재 선택 맵을 지연 로드합니다.

## 연출

- 정령별 일반탄/특수탄의 탄체, 색, 꼬리, 파티클 차등화
- 정령별 착탄/폭발 파티클 차등화
- 현재 턴 정령 위 움직이는 화살표
- 바람 방향에 맞춰 흐르는 맵별 파티클
- 캐릭터 직접 명중 때만 짧은 화면 진동
- 특수탄 직격은 일반탄보다 약간 강한 화면 진동
- 지형 착탄만으로는 화면 진동 없음

## 사운드

- 배경음: `assets/bloombit.mp3`
- 효과음: `assets/bloomshot-sfx.ogg` Audio Sprite 1개
- 큐 정보: `assets/sfx-cues.json`
- 캐릭터 8종 × 일반/특수 발사음 16개
- 캐릭터 8종 × 일반/특수 착탄음 16개
- 보급/아이템 계열 4개

## 보급 상자

낙하산 보급과 착지 상자는 픽셀아트 이미지 에셋을 사용합니다.

- `assets/supply-crate.png`
- `assets/supply-crate-ground.png`

## UI

선택 화면과 전투 HUD는 블룸샷의 정령/픽셀 아케이드 분위기에 맞춘 별도 테마를 사용합니다. 모바일에서는 하단 HUD 높이와 버튼 간격을 줄이고 작은 화면에서는 아이템 슬롯을 4열×2행으로 배치합니다.

## 멀티 동기화

게임 상태 버전은 `7`입니다. 다른 블룸샷 버전과 혼용하면 새 버전 안내를 표시합니다. 서버에는 기존 중계 구조를 그대로 사용하며 Worker를 교체하지 않습니다.
