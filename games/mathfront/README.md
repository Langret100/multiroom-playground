# MATHFRONT 개선판
현재 게임은 원본의 로컬 4대4 봇 훈련 모드입니다. 온라인 실시간 대전은 구현하지 않았습니다. 멀티룸 게임 목록에 1인 훈련으로 등록했습니다.

- 거점 A(-19,29), B(0,0), C(19,-29): 직선 배치 제거. 마당/시장/창고, 여러 문, 교차 연결, 낮은 엄폐, 숙이기 통로.
- WASD 이동, Shift 달리기, Space 점프, Ctrl 누르기/C 토글 숙이기, 우클릭/Q 조준, G 수류탄, R 재장전, F2 성능표.
- ADS 시야각 74→52도. 카메라 조준점과 총구 출발점을 함께 계산하며 벽 가림을 검사합니다.
- 수류탄: 2.25초 지연, 3m 이내 최대120, 12m 밖0, 거리에 따른 감소와 벽 차폐. 화염/충격파/연기/잔해 및 녹음된 소리.
- Kenney CC0 모델과 여성을 포함한 8종 텍스처. 공개 Run/Idle 모션을 오프라인 스키닝해 사용, 양손 총 자세와 숙이기는 수정 포즈. 점프는 기존 플레이어 물리 동작입니다.
- 맵 정적 지오메트리 한 번의 GPU 호출, 낮은 렌더 해상도/자동 조절. 웨일북 60FPS 목표이며 실제 기기 미측정으로 보장하지 않습니다.
- 검증: 조준/총구27조합, 폭발 거리/차폐/아군보호/물리, 두 스폰에서 모든 거점 길 연결. 브라우저 화면 확인.

맵은 독자 제작이며 원작 맵/캐릭터 리소스를 복제하지 않았습니다. 에셋 출처와 라이선스는 ASSETS.md 및 assets의 License 파일에 있습니다.

## 무기 보급 및 수류탄 업데이트
기본 소총/기관단총/산탄총/저격총(각각 다른 CC0 모델). 저격총은 스코프와 긴 총열, ADS22도. 모두 기본 소총으로 시작하며 추가 무기는 보급함 및 쓰러진 상대의 드롭에서 획득합니다. 보급함 근처 E 획득, 18~30초 뒤 무작위 재보급. G 누른 동안 예상 궤적을 보며 방향 지정, G 놓기 투척, 우클릭 취소. T로 파편/연막/섬광 선택. 연막12초, 봇 시야 차단; 섬광은 거리/시선/벽 차폐를 반영. 봇 사망 시 넘어져8초간 시체 유지,30초 후 재배치. 터치 노트북 마우스 입력 분류 수정, 포인터 잠금 실패 시 마우스 이동 대체 입력.

건물2동은 입구/사격 창문/외부 계단/옥상 착지 구역을 갖췄습니다. 지상과 지붕은 높이별 분리 처리. 실제 CC0 Minigolf 깃발 모델 적용. 접지 그림자와 건물 바닥 그림자는 그림자맵 없이2회 GPU호출로 처리하며 사실적인 실시간 그림자를 흉내내는 경량 효과입니다. 비조준/조준/이동/점프/연사 탄퍼짐 및 크로스헤어 반영. 사망은20개 물리 관절, 연결 제약, 바닥/벽 충돌과 스키닝으로 처리합니다. 안정된 시체는 물리 갱신을 멈춥니다.

최근 수정: 기본총 비조준 퍼짐0.048, 정지 조준0.0022. 연사 회복 지연180ms, 이동/점프 추가 퍼짐. 크로스헤어 네 방향 끝이 실제 퍼짐에 맞춰 확장하며 중심점 고정. 계단에 실제 측면 충돌을 추가했고 높이0.38m 이내 단차만 올라갑니다. 20개 계단 연속 이동/높은 옆면 통과 방지 검증. 래그돌 접지 관절 및 실제 스킨 메시 지면 접촉 검증.

## 양측 균형/옥상/회복/깃발 개선
지형과 충돌체, 실외/실내 계단, 옥상 바닥, 초기 무기 보급을180도 회전 대응하도록 배치. 두 팀의4인 시작 위치도 대응합니다. A/C는 서로 대칭이며 B는 중앙 광장에 배치했습니다. 실내 계단 양쪽20개 단차와 옥상 개구부 통과를 검증했습니다. 회복팩4개는 양쪽 대칭 배치,35회복/100상한/16초 재생이며 플레이어와 봇 모두 사용할 수 있습니다. 깃발 천을 넓히고 세분화, 금색 띠와 마름모 문양을 추가했으며 GPU정점 셰이더로 바람에 흔들립니다. 구조적 대칭 검증이며 장시간 플레이 승률 검증이나 실제 웨일북 성능 측정을 대신하지 않습니다.

HUD: 미니맵 좌측 상단, 아군만 위치 표시. 좌측 하단 초상화/역할/빈 보호막/체력 표시와 상단ABC중복 표시 제거. 탄약 옆16px세로 체력바로 통합, 체력 감소에 따라 청록색에서 붉은색으로 변화.


## 최종 전투 규칙 및 모바일
상대 처치 +1점, 거점 점령 +5점(중복 점령 보상 없음), 소유 거점의 자동 점수 제거. 사망30초 대기와 점령 거점 선택 부활, 문제 정답 시 대기 없이 위치 선택. 소유 거점이 없으면 시작 위치 부활. 아군 거점 내부 초당5HP 회복. 봇 사망 무기20초 유지, 근처2.2m에서 E/터치 무기 획득. 모바일 이동/시점/조준/발사/점프/달리기/숙이기/재장전/수류탄 종류/누르고 준비 후 놓아 투척. 시작 화면의 터치 컨트롤 사용으로 수동 전환 가능. 화면 회전 및 앱 전환 시 입력 정리. 저사양 프로필은 적응 해상도, 안티앨리어싱 제거, 시체 변형30Hz, 투영HUD20Hz. 실제 웨일북60FPS는 기기 검증이 필요합니다. 새로 탐색한 캐릭터는 적용하지 않았습니다.


산탄총: 8펠릿, 탄당19, 비조준 원뿔0.115/조준0.080, 6m부터 선형 피해 감소 및22m 제한. 펠릿별 정규화 방향, 산탄 헤드배율1.25. 로켓런처: 2발, 발사 간격1.3초, 속도36m/s, 최대 비행2.2초, 착탄/비행 종료 폭발. 1.5m 이내110피해→7m 밖0, 벽 차폐/아군 보호/자해65%, 보급 무작위 풀 포함. 기본 소총/SMG/산탄총/저격총/로켓런처 총5종.


HUD v8: 성능표 숨김, 미니맵 내부 테두리/그림자 제거해 외곽선 하나만 유지. 화면 거점은52% 불투명 알파벳과 소유팀 색만 표시. 킬피드/중앙 알림/점수 배경 제거. 보급함4개에서 최대8개로 확대하며 새 위치는 지상 충돌/180도 대칭을 확인해 선택합니다.


v10: 사망 무기 드롭/수명/획득/렌더 코드 제거. 추가 무기는8개 보급함에서만 획득. 깃발 천을 양면 직사각형 메시로 다시 만들고 이전 잔여 부품 제거. 미니맵124px(모바일78px), 배경 불투명도42%.
