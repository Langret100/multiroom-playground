# 매스프론트 전초기지

무료 Kenney CC0 총기·상자·표적을 로컬로 포함한 원본 게임의 시각 개선 버전입니다.

WASD 이동, Space 점프, Shift 달리기, 좌클릭 연사, 우클릭 조준, R 재장전, F2 성능표. 모바일 이동/시점/발사 패드를 유지했습니다. A/B/C 구구단 점령 및 4대4 봇 전투를 유지합니다.

현재 싱글 봇 훈련입니다. 온라인 플레이어 동기화 및 서버 판정은 구현하지 않았습니다. 멀티룸 게임 목록에는 최대 1인 훈련으로 등록했습니다. 실제 배포 서버와 방 생성은 별도 확인이 필요합니다.

전체 ZIP을 풀어 기존 프로젝트에 적용하거나, 패치 ZIP의 games/mathfront 폴더와 js/games/registry.js 파일을 덮어쓰세요. 정적 웹 서버에서 실행하세요. 외부 CDN이 필요 없습니다.

에셋 출처: https://kenney.nl/assets/blaster-kit (CC0). 라이선스는 assets/Kenney-License.txt 참조.

## 수류탄과 조준 업데이트
우클릭 유지 또는 Q로 조준 전환. 조준 시 총기를 축소하고 아래로 내렸습니다. G로 수류탄을 투척합니다(모바일 GRENADE). 2.25초 지연 폭발, 반경 7m, 벽에 튕김, 7초 재사용 대기시간. 적 피해와 자기 피해가 있으며 아군 봇은 피해를 받지 않습니다. 엄폐물 뒤는 폭발 피해를 차단합니다. 문제창에서는 수류탄도 일시정지됩니다.

녹음된 SKS 총격과 소총 재장전, Kenney 폭발/금속음 파일을 사용합니다. 출처와 CC0 라이선스는 ASSETS.md 및 assets/audio 폴더에 포함했습니다.
