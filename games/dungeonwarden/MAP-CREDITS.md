# 맵 에셋 출처 v0.4

현재 기본 맵은 Kenney의 실제 CC0 3D 모델을 WebGL로 렌더링합니다.

| 팩 | 출처 | 사용 |
|---|---|---|
| Mini Dungeon 2.0 | https://kenney.nl/assets/mini-dungeon | 벽·바닥·기둥·배너·문·상자·함정·장식 |
| Mini Arena 1.1 | https://kenney.nl/assets/mini-arena | 아레나 벽·바닥·기둥·조각상·배너 |
| Mini Forest 1.0 | https://kenney.nl/assets/mini-forest | 아레나 숲 구역의 나무·식물 |

원본 라이선스는 assets/mini/{dungeon,arena,forest}/License.txt에 보존합니다. 원본 OBJ의 좌표와 컬러맵 색상을 추출하고 면 조명을 계산해 selected-models.json에 저장했습니다. 원본 모델 자체를 사용하며, 2D 타일을 입체인 것처럼 표시하는 방식이 아닙니다. 런타임에는 텍스처·모델 로더 없이 선택한 데이터만 내장합니다. 그림자는 간단한 바닥 음영으로 대체합니다.

WebGL을 사용할 수 없는 경우 기존 0x72 DungeonTileset II CC0 타일 렌더러로 돌아갑니다. 출처 https://0x72.itch.io/dungeontileset-ii . 캐릭터·장비 최종 픽셀 스프라이트는 추후 교체하는 임시 코드 그림입니다.

## v0.4.2 방 구조·오브젝트 다양화

던전 방 크기를 32×30, 40×34, 30×42, 46×30, 36×44, 42×36, 34×32, 48×40걸음으로 나눴다. 창고·병영·폐허·작업장·성소·왕좌에 맞게 통, 항아리, 탁자, 의자, 목재 구조물·지지대, 바위, 돌더미, 낮은 벽과 기둥을 조합한다. 아레나 숲 방은 나무와 바위로 구성한다. 모든 고정 장애물은 보이는 크기와 동일한 바닥 영역으로 이동과 시야를 막는다. 출입구 통로와 상자·몬스터 시작 위치는 비워 둔다.

Kenney Mini Dungeon의 실제 CC0 OBJ 모델을 추가해 준비된 환경 모델은 29개다. 새 장애물도 기존 오브젝트 배치 버퍼에서 함께 그린다. 자동 테스트 68개 통과(방 크기·모델 다양성, 통로, 충돌, 기존 AI 최종 방 도달 포함). 데스크톱 화면에서 병영·폐허의 서로 다른 구조와 브라우저 오류 없음을 확인했다. 구형 휴대폰의 실기기 60fps는 별도 측정이 필요하다.
