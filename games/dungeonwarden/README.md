

게임 등록은 **던전 아레나** 한 개입니다. 로비에서 던전 아레나 방을 만들고 방 안의 경기 방식에서 방장이 모드를 선택합니다. 모드 선택은 대기 중에만 가능하며 모든 참가자에게 동기화됩니다.

- **아레나 모드**: 시작 위치를 10초 안에 고르고 장비를 모아 용암을 피해 마지막까지 생존합니다.
- **던전 모드**: 방장이 던전마스터로 몬스터·함정·보물을 배치하거나 보스를 조작합니다. 나머지 참가자는 모험가로 던전을 공략합니다. 혼자 시작하면 AI 모험가가 공략합니다.

PC: WASD 이동, Shift 질주, 클릭/Space 일반 공격, 우클릭/Q 특수 공격, E 줍기/상자, I/Tab 장비, M 지도. 모바일: 왼쪽 조이스틱, 오른쪽 공격·특수·상호작용 버튼.

바닥 드랍은 문제 없이 바로 줍습니다. 문제는 보물상자에만 적용됩니다. 온라인 설정창을 열어도 경기는 계속 진행됩니다. 경기 도중 새 참가자는 다음 경기에 참여하며 기존 참가자는 재연결할 수 있습니다. 모험가가 퇴장하면 해당 캐릭터는 AI가 이어받습니다. 마스터가 퇴장하면 해당 경기를 종료하고 방으로 돌아갑니다.
